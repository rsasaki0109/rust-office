# 日常利用に向けた 90% ロードマップ

## 評価の範囲

目標は、Writer・Calc・Impress で日常的な文書・表計算・スライドを作成し、
保存、再編集、共有できる状態。Microsoft Office / LibreOffice 全機能との
互換性を 100% とした評価ではない。

2026-10-09 の基準値は **45%（9 / 20 項目）**。下記の各項目を 5 点とする
プロジェクト内の達成度であり、品質の測定値や外部ベンチマークではない。
以前の約45%という概算を、確認可能なチェック項目に置き換える。
チェック済み項目も、既存の MVP 範囲の達成を示す。

項目を完了にするには、main へのマージ、対象の回帰テスト、実際の操作確認、
保存・再読込または配布確認の証拠を残す。テスト件数や PR 件数だけでは加点しない。
未マージの変更は進行中として扱う。

| 分野 | 配点 | 現在 | 未達の主要項目 |
| --- | ---: | ---: | --- |
| データ保護・安定性 | 20 | 10 | 全形式の破損入力対応、復旧・大きな入力の制限 |
| Writer | 25 | 15 | 検索・置換、セクションごとのページ設定 |
| Calc | 20 | 10 | セル書式・シート管理、複数シートの集計・グラフ |
| Impress | 20 | 5 | 図形・配置、スライド操作、発表・共有 |
| 配布・使いやすさ | 15 | 5 | Windows/macOS、IME・アクセシビリティ確認 |
| 合計 | 100 | 45 | 90点に向けて残り45点 |

## 達成チェック

### データ保護・安定性（20点）

- [x] 保存失敗時に元ファイルと未保存編集を保持する。
- [x] 新規作成・Open・終了の確認と、失敗時の文書・保存先・履歴保持が機能する。
- [ ] DOCX / ODT / PPTX / XLSX / CSV の壊れた入力と必要な参照の欠落を検出し、
  部分的な読み込みによる内容欠落を防ぐ。ODT は [PR #10](https://github.com/rsasaki0109/rust-office/pull/10) が進行中。
- [ ] クラッシュ後の復旧用コピーと、読み込み・展開・描画の大きな入力に対する
  制限を備える。強制終了と復旧、制限超過後の編集継続を確認する。

### Writer（25点）

- [x] 入力、選択、基本書式、Undo/Redo、複数ページの編集が機能する。
- [x] 表、埋め込み画像、リスト、リンク、基本ヘッダー／フッターを編集できる。
- [x] JSON / DOCX / ODT の基本保存・再読込と、レイアウトに沿う PDF 出力が機能する。
- [ ] 検索・置換：日本語、次／前、全置換、該当なし、Undo/Redo を扱い、
  表・ヘッダー／フッターなどの検索範囲を明示する。
- [ ] セクションごとの用紙・余白・向き・ヘッダー／フッターを編集し、
  DOCX / ODT / PDF の保存・再読込で維持する。

### Calc（20点）

- [x] 基本数式・集計・エラー伝播と、循環参照・評価量の制限が機能する。
- [x] 範囲編集、相対／絶対参照コピー、Undo/Redo、CSV / XLSX の基本入出力が機能する。
- [ ] セルの数値／日付書式、基本装飾、列幅・行高、シート名変更・削除を扱い、
  XLSX の再読込で維持する。削除確認と Undo/Redo も確認する。
- [ ] シートをまたぐ参照・集計と、棒／折れ線グラフの作成・更新・保存を備える。

### Impress（20点）

- [x] 基本スライド・テーマと JSON / PPTX のタイトル・本文入出力が機能する。
- [ ] テキスト枠・画像・基本図形を選択、移動、サイズ変更でき、保存後も維持する。
- [ ] スライド複製・並べ替え・削除、オブジェクト操作の Undo/Redo を備える。
- [ ] 全画面の発表、次／前・終了操作、PDF 共有と PPTX の基本図形出力を備える。

### 配布・使いやすさ（15点）

- [x] Linux のテスト・Clippy・リリースビルドと配布バイナリを CI で生成する。
- [ ] Windows / macOS のビルドと配布成果物を CI で生成し、各 OS で
  起動・日本語入力・Open・Save・終了を確認する。署名／未署名の状態を明記する。
- [ ] 主要操作にキーボードアクセスとアクセシビリティ情報を備え、
  日本語 IME の確定・取消、コピー／貼り付け、フォーカス移動を各 OS で確認する。

## 進め方と完了判定

1. ODT 安定化を完了し、データ保護の既存動作を揃える。
2. Writer の検索・置換を、モデル、UI、書式・保存への影響を確認できる単位で実装する。
3. Calc のセル書式・シート管理と、Impress の図形・スライド操作を小さな PR で進める。
4. セクション互換性、発表・PDF、複数シート集計・グラフを進める。
5. 復旧・入力制限、Windows/macOS 配布、IME・アクセシビリティを検証する。

**90%到達条件**は18項目以上の完了に加え、データ保護の4項目、3 OS の配布確認、
主要なキーボード・IME 操作の確認が完了していること。残る2項目は未対応範囲として
明記する。重大なデータ損失・起動不能・保存不能が残る間は90%とは報告しない。

各 PR に再現例、変更後の動作、検証結果、互換性の限界を記載する。
完了項目に対応する PR・CI・手動確認の記録を更新し、再発時はチェックを戻す。
現在の機能と制約の詳細は [DEVELOPMENT.md](DEVELOPMENT.md) を参照。
